# Mostashar V61 — Separated Lesson Player

V61 moves the student lesson page and supported video playback to the separated frontend while keeping authorization, enrollment, drip rules, playback grants and protected media enforcement in FastAPI.

## Security boundaries

- The separated frontend never receives the permanent Cloudflare Stream UID as a playable URL.
- Cloudflare playback uses a short-lived edge grant generated by the backend.
- Direct MP4/WebM playback, when explicitly enabled, uses the existing session-bound `/protected/video/{lesson_id}` proxy with a short-lived signed token.
- Unsupported legacy embeds remain on the backend protected lesson page until migrated to the approved streaming/DRM provider.
- Watermark text is derived on the server from user, lesson and authenticated session record.
- Enrollment, schedule and drip access checks are executed before experience data is returned.
- Protected lesson assets remain backend routes and never expose storage keys.

## Migration state

Separated now: student dashboard, course/lesson list, lesson body, supported protected player, flashcards, lesson assets and homework links.

Backend fallback remains for: legacy third-party embeds, interactive checkpoint submission UI, study assistant forms, discussion posting, and offline DRM grants. These can move in later releases behind dedicated API contracts.
